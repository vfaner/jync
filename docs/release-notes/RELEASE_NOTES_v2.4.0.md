# Jync v2.4.0

## 新增

- **AI 运维助手**：内嵌悬浮窗（ADMIN / OPS），接入大模型后用自然语言查询任务状态、进度与吞吐、源 / 目标行数、数据库性能、当前告警与 ETL 最近结果；变更日志断流时逐项自检前提（连接、权限、位点、跳过计数；这一步会连源库，一次对话最多 2 次）。共 11 个只读工具，按「告警 → 任务 → 日志流 → 自检 → 文档」排障，回答注明依据来自哪个工具；建任务只生成草稿，由人打开表单确认。回答按 Markdown 渲染，产品用法来自随包知识库、不联网检索。支持 OpenAI 兼容、Anthropic 与 Ollama（原生 / 兼容层）流式工具调用。
- **角色与资源归属**：账号分为系统管理员（ADMIN）、运维（OPS）与访客（VIEWER）。运维可查看全部资源，但新建、编辑、删除、运行只作用于自己名下的连接、项目、ETL 任务 / 批次、迁移与 Redis 目标；访客只读。越权编辑、引用他人资源或在他人项目上发起 AI 草稿 / 校验会被拒绝（页面跳 `/?denied`，API 返回 403 JSON）。空库启动自动创建 `admin` / `ops` / `view` 三个账号（默认密码 123456，首次登录强制改密）；旧库升级自动补一个 `ops`，手动删除后重启不复活。
- **外部认证运维名单**：外部认证页新增「运维用户名」，逗号分隔、精确匹配；同时命中管理员名单时按管理员处理。未填写时外部用户仍是访客。
- **AI 总开关**：系统配置页新增「AI 辅助」卡片，关闭后 AI 菜单、草稿按钮与全部 AI 接口一起失效；`sync.ai.enabled=false` 为部署级硬关，页面开关置灰且无法覆盖。
- **ETL 运行序号**：新增内置变量 `${runIndex}`，读取任务已成功运行的次数：首次运行读到 0，成功一次加 1，失败不计数；新建任务或修改取数配置 / 变量后从 0 重新开始。

## 优化

- **按角色渲染入口**：新建、编辑、删除、启停按角色与归属显示，服务端统一以 `canEdit(owner)` 判定；补齐引用归属校验，堵住借用他人连接凭据与越权引用；连接表单的「探测驱动」与进程指标向运维开放，系统配置、外部认证、告警、审计、AI 配置与配置包仍仅管理员。
- **ETL 一致性**：删除任务、修改取数 SQL、删除批次或成员期间先持有执行租约，运行不会在检查与写入之间插入；SQL 词法按方言解析（PostgreSQL 的 `'C:\'`、SQL Server 的 `#tmp`、块注释嵌套），保存、预检、运行与派生表包装同一口径；MongoDB 断点键类型不稳（Mixed / 全 Null）直接拒绝，避免跳数或重放。
- **界面**：导航、登录页、浏览器 favicon 与 iOS 主屏图标统一为同一套设计，位图裁剪优化后为 1.5 KB / 9 KB。

## 修复

- **CDC**：重连时先断开上一轮客户端，避免相同 `server_id` 并发触发 SERVER_ID_CONFLICT；空事务按边界推进位点，只读库 binlog 被 purge 后不再误判 PURGED 停机（存在 XA prepare 分支时不前进）；停机门闩生效，shutdown 后不再拉起消费者。
- **AI 对话**：同一轮多个工具结果合并为一条消息、相邻同角色文本合并，历史里失败的提问不再让后续对话 400；超出每轮上限的工具调用也补 `tool_result`；只有端点明确不支持工具时才降级为文档回答，`tool_use` / `tool_result` 形状错误不再被误判；畸形工具参数回填空对象；供应商错误正文（订阅到期、密钥无效等）回显到悬浮窗；草稿按过期时间清理。

## 已知边界

- 升级前创建的连接、项目与任务没有归属（视为系统所有）：运维只能查看，不能编辑，也不能在新任务里引用；需要运维继续维护的只能由管理员重建或由管理员继续管理。
- 外部认证的运维名单需要显式填写，升级不会自动把任何外部用户提升为运维。
- AI 页面开关在单节点上立即生效，多节点部署各自缓存 5 秒；AI 助手只读且有预算（工具结果上限、每轮工具数与对话耗时），没有启用供应商时不产生任何外部请求。
- `${runIndex}` 的语义是「成功运行次数」：失败不计数，重试读到同一值；改动取数配置或变量后归零，范围覆盖自动清断点但不会重置它。
- 访客仍看不到需要写权限的页面配置（Redis 目标列表、迁移连接列表等），与 v2.3.0 一致。

## 升级

替换 `jync.jar` 并重启即可。元数据库启动时自动补齐新列：资源表新增可空 `owner_username`（旧数据 = 系统所有），`oa_auth_config` 新增可空 `ops_users`，`etl_task` 新增可空 `run_index`（按 0 读取），并写入一次性标记 `seed.local-ops`。既有连接、项目、ETL、迁移与 AI 供应商配置无需迁移。运行环境仍需 Java 17 或更高版本。
