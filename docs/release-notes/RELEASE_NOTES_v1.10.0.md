# Jync v1.10.0 · 性能曲线与 SAP HANA

新增数据库与同步任务性能曲线、可选的 Prometheus 指标端点，六种分析型引擎接入实时同步，SAP HANA 升级为实时同步类型；同时修正了 CDC 延迟口径与一批同步正确性问题。

## 新增

- **性能曲线**：新增数据库性能页与同步任务性能页，覆盖连接延迟与可用性、库内会话 / QPS / 缓存命中率 / 锁等待、表数 / 行数 / 占用空间，以及每个任务的同步行数、延迟、失败次数、变更构成与变更最多的表；看板趋势图改为实时同步与 ETL 双曲线，可在「变更数 / 行数」之间切换。采样由后台定时执行，历史保留 7 天。
- **Prometheus 指标端点**：`GET /api/metrics/prometheus` 输出进程、任务与连接三组最新样本；默认关闭，配置 `metrics.prometheus-token`（或 `JYN_METRICS_TOKEN`）后以 Bearer token 访问。
- **分析型引擎作同步源**：Doris、ClickHouse、Hive、Impala、Elasticsearch、MongoDB（Atlas SQL）可作为实时同步的源，策略为轮询与全表比对；它们不会出现在目标下拉中。六个引擎一律按无主键读取，避免把驱动报告的排序键当成唯一键而折叠数据。
- **SAP HANA 实时同步**：新增 HANA 方言家族与结构同步、轮询式数据同步；写入用 `UPSERT … WITH PRIMARY KEY`，分页走 `LIMIT / OFFSET`，视图与存储过程/函数用 `CREATE OR REPLACE` 重建，表注释走 `COMMENT ON`。

## 优化

- 任务详情页与 ETL 表单拆成模块化模板：新增数据库专属卡片时不再牵动其它模式，页面结构与交互保持不变。
- CDC 状态卡按可用宽度自动排成多列，位点与错误各占整行，手机端回退单列。

## 修复

- **CDC 延迟口径**：MySQL / PostgreSQL / 崖山改用源提交时刻计算延迟，不再按「距上一条事件多久」或「现在」计时，面板改为显示「上次事件」时刻；源库空闲时显示 0，重连追赶的事件不再计入。
- **CDC 解析与权限**：SQL Redo 解析支持无空格的 `IS NULL` 与带空格的列名；达梦补齐最旧可挖 SCN，并用 `ALL_TAB_PRIVS` 检查普通用户权限；PostgreSQL `money` 兼容欧洲 locale（`1.234,56`）。
- **CDC 故障归类**：ORA-01284 与 ORA-00308 一样归为归档缺失；SQL Server 接受 `db_owner`；YStream 重连时重置 `lastSeen`，避免跳过未提交的事务。
- **同步正确性**：行数审计开始上报目标多出行并触发数据漂移告警；删除比对按主键比较前去掉 CHAR 尾部空格；关闭索引同步时清理待建队列；删除项目时一并清理分块装载续传点。
- **Oracle / DB2 schema 折叠**：同步、数据预览与索引探测统一按字典大小写折叠，避免小写 schema 指向不存在的库、有索引的表被误报为无索引。
- **指标口径**：MySQL / DB2 / Oracle 缓存命中率按逻辑读口径计算，物理读大于逻辑读时显示未知；SQL Server 缓存命中率改取分子 / 分母计数器；性能页「进程 CPU」改读 JVM 进程自身负载。
- **采样与图表**：数据库采样覆盖连接列表中的每条连接，重启后约 30 秒出首采；轮询任务延迟改用最近一次成功周期；没有目录统计的产品容量显示「—」；停用项目上的「立即同步」也会产生采样；只有一个采样点时画出孤立点，图表不再空白；删除连接或项目时级联清理对应样本。
- **性能页显示**：纵轴刻度按步长取整齐值，状态标签走 i18n（不再直接显示 `RUNNING`），延迟与占用空间按量级换算（`1 s 992 ms`、`1 GB 2 MB`），没有变更的时间段显示空档说明。
- **图表绘制**：折线控制点夹进相邻采样区间，曲线不再画到 0 以下或冲过峰值；面积图渐变 id 全局唯一，项目页两条曲线不再串色；变更类型占比图例改用中文译文。

## 提醒

- 六种分析型引擎按无主键读取，增量只识别新增，没有更新 / 删除识别；需要收敛时请使用全表比对。
- 性能采样会在被监控库上打开会话（默认 5 分钟一次），库内指标依赖账号权限；不需要时把 `metrics.enabled` 设为 `false`。Prometheus 端点默认关闭，`prometheus-token` 留空即不暴露。
- 本次无破坏性变更，替换 `jync.jar` 重启即可；升级前备份 `./data` 与 `application.yml`。
