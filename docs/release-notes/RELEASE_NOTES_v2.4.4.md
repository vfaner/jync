# Jync v2.4.4

## 本版概要

v2.4.4 以**数据正确性与日常运维体验**为主：修复跨库时间主键导致的同步删除误判、CDC 位点 / 租约与 ClickHouse 时区绑定等数据问题；新增变更 / 审计 / 系统日志的按日期清理与三档保留期；看板资源环与底部双卡重做，AI 智能体补充日志保留期查询与更清晰的诊断边界。建议所有 2.4.x 用户升级。

## 新增

- 变更日志、审计日志与系统日志支持按日期删除：所选当天包含在内，今天永远保留，清理动作本身再记一条审计。
- 三类日志的保留期可配置并自动执行：变更日志与审计日志默认 180 天，系统日志默认 30 天。
- 看板顶部「实时状态」徽标随每 10 秒刷新显示最新时间，统计卡并列显示异常任务数。
- 看板底部「同步任务概览」与「最近活动」统一胶囊徽标头，数字变化时跳动提示，仍保持左右并排。
- 看板与性能监控页的区块标题统一为胶囊徽标头，图表卡头补充品牌色图标。
- 列清洗卡改为可筛选、可搜索的表格，显示每列累计同步量与游标策略；CDC 项目在进度模块隐藏无关列。
- AI 运维助手新增「日志保留期」查询，直接回答三类日志与指标实际生效的保留窗口。
- 新增 Docker 官方镜像发布流水线（Docker Hub / GHCR，amd64 + arm64），容器内「一键升级」改为展示镜像更新命令。

## 优化

- 指标采样共用连接、进度统计改为 SQL 求和、单例行按主键读取，性能页刷新明显更快。
- 租约续租改为节流提交，仪表盘聚合过滤掉无效行，CDC 位点表加上限，减少后台常驻开销。
- Mongo 结构发现的计数改为并发执行；ES 滚动分页按平均文档大小封顶，大库不再拖垮内存。
- 迁移抽样校验合并为一条 IN 查询，批量写入增加字节预算，既提速又避免整批反序列化。
- AI 诊断工具改走轻量指标路径，不再为一次问答聚合整张变更日志。
- AI 运维助手对 Ollama 供应商自动关闭思考，短问答不再被思考模型拖慢；新增 Anthropic 提示词缓存与有界并发队列。
- 知识库与提示词补充日志保留期、Cron 语法差异、看板实时状态与操作边界，检索片段上限放宽，关键段落不再被截断。
- 按日期删除弹窗改用页面自绘日历：点输入框整块展开，月份可翻页，今天 / 清除一键，截止上限之后的日子禁用。
- 看板四块资源环支持悬停/键盘聚焦查看已用、可用与使用率，环上浮并泛同色光晕；CPU 卡补充处理器型号、物理/逻辑核心与系统，点击可展开占用率 top5 进程（只读）。

## 修复

- 修复删除同步在源端时间类型主键上比较失真、可能误删目标行的问题：所有主键读取统一按驱动值归一化。
- 修复 AI 端点 SSRF 与错误信息回显、生产源直连越权、DDL 规范化与驱动类注入等安全问题。
- 修复 SQL Server CDC 捕获实例列名取错、双捕获实例丢行、DDL 修复后投影缓存不失效。
- 修复 ClickHouse 源在非 UTC 时区部署时水位按 JVM 时区偏移、全量/增量窗口读不到行的问题。
- 修复 SQL Server 多捕获实例时一轮行预算截断后仍持久化更高 LSN，重启会静默跳过未读行。
- 修复 PostgreSQL 逻辑解码事务被 max_changes 反复截断时空转、面板全绿但位点不前进。
- 修复 CDC 在无原生 upsert 的目标上重投「值未变化」的 UPDATE 时误报重复键、事务永远无法落地。
- 修复 CDC 目标提交后租约被接管被误记为写失败、可能在对端写 ERROR 帽的问题。
- 修复 ETL 预检不校验变量展开后的 SQL，出现「预检通过、运行却拒绝」的不一致。
- 修复变更日志的 DROP TABLE / DROP VIEW 待办在目标表本就不存在时永远失败：默认按 IF EXISTS 执行，Oracle/DM/崖山自动去掉子句并把「对象不存在」视为完成。
- 修复专属迁移在源与目标指向同一搜索引擎、默认覆盖模式下会先删掉源索引并报成功的问题。
- 修复 AI 语法检查会执行候选里的第二条语句且不回滚的问题：视图多语句直接拒绝，校验在事务中回滚。
- 修复 AI 流式响应在 HTTP 200 后返回错误事件时被当作成功、半截 SQL 可能被保存的问题。
- 修复启动失败分析只遮蔽 `password=` 参数、Oracle thin 的 `user/口令@` 会写进日志与错误页的问题。
- 修复登录 POST 不带 username 字段时绕过锁定，可持续消耗 BCrypt 与审计的问题。
- 修复告警健康检查共用 8 秒预算把已完成或尾部连接误判超时、触发假 DB_UNHEALTHY 的问题。
- 修复 MySQL TIMESTAMP/DATETIME 主键与其它数据库族比对时一边按墙钟文本、一边按时间对象，开启同步删除会误删整张目标表的问题。
- 修复 kill -9 后遗留的 RUNNING 状态因未过期租约无法自愈的问题：启动后每分钟复查，租约过期即复位。
- 修复 SQL Server CDC 整窗物化导致的内存溢出，改为按事务边界分块处理。
- 修复 ETL 续跑偶发冻结与静默丢行，ES 分片失败不再被当作成功。
- 修复游标列全为 NULL 的表每轮全量扫描、无主键表永久报错，以及游标缺值跳过时删除不传播。
- 修复 MySQL TIMESTAMP 按会话时区读取导致预览与校验失真，改为按墙钟读取。
- 修复 CDC 空转时位点不落盘、重连锚点错误、Error 状态被吞。
- 修复位点重置与节流缓冲的竞态，杜绝重跑基线后复活旧水位；表选择索引改为快照发布，消除并发空指针。
- 修复专属迁移把唯一索引冲突当作已存在、启动恢复误认领其他节点的运行。
- 修复批次里仅大小写不同的两张表在折叠目标上互相覆盖，以及极值 TIME / 二进制列被写成无法原样回读的续跑键、任务此后永久失败。
- 修复 DB2 / SQL Server 续跑 ETL 被冗余 ORDER BY 卡死，以及 H2 元数据库文件损坏时的启动失败页报错。
- 修复审计日志到期清理在定时任务里因缺少事务而静默失败，保留期现在真正按天生效。
- 修复登录锁定从达到阈值后才开始计时（此前多给一次尝试），AJAX 端点越权或异常时不再返回 HTML 重定向。
- 修复 AI 助手取消定时器残留、页面关闭立即取消、首行看门狗超出预算的问题。
- 其余若干小项一并修复：续跑 ETL 把 `AS top` 别名误判为限流子句、匿名请求的审计归属显示为 anonymousUser、登录页账号提示漏掉 ops、助手 `cdc_probe` 的说明与实际权限不一致、下拉菜单当前页高亮、弹窗层级与关闭按钮、看板排版与文案。

## 测试

6611 个测试：6610 通过，0 失败 0 错误，1 个仅限 Linux 的用例在 macOS 上按环境跳过。新增回归用例覆盖删除同步键归一化、CDC 捕获实例、位点重置竞态、ETL 续传、AI 截断与权限边界等场景；`*IT` 真库用例需 Docker 另跑。

## 升级

替换 `jync.jar` 并重启即可。本版新增两列元数据字段（`migration_run.run_node`、`sync_progress.full_load_without_cursor`），启动时由 Hibernate 自动补齐；升级前请照常备份数据目录。运行环境仍需 Java 17 或更高版本。
