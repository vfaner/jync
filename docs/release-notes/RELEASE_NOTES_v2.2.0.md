# Jync v2.2.0

## 新增

- **TLS「服务器路径」证书模式**：证书页新增路径标签页，密钥库或 PEM 填服务器绝对路径即可，原地替换文件完成续期，无需重新上传。
- **配置文件证书模式**：`app.tls.keystore-path`、`pem-cert-path` 等键或环境变量在启动时读取挂载证书，页面只读。
- **更新检查开关**：系统配置页可关闭版本检查，关闭后不再访问 GitHub / Gitee；配置文件显式设置时页面只读。
- **看板新版本弹窗**：管理员登录看板时自动提示新版本，「立即更新」复用一键升级，「忽略此版本」记服务端、重启不丢。
- **更新圆点上提导航**：「系统管理」折叠时也显示橙色圆点，展开后「系统信息」项保留第二枚。
- **外部元数据库 Compose 示例**：新增 MySQL / PostgreSQL / Oracle 三份示例，数据库健康检查通过后才启动 Jync。

## 优化

- **系统配置页重新分工**：元数据库块移到「系统信息」，TLS 证书表单占左列，配置包 / 诊断包 / 强制 HTTPS 叠右列；配置包导出导入合并为标签页。
- **移除元数据库连接测试器**：该表单只做一次性探测，不决定生效的元数据库；页面只保留「由启动环境决定」的说明。

## 修复

- **CDC 待办在 PostgreSQL 元数据库上查询失败**：LOB 列按 `oid` 比较始终落空；改用 `details_hash` 与 `resolution_status`，启动时为旧行自动补哈希。
- **CDC 目标表重建后关闭对应待办**：重建已对齐结构与数据，跳过 DDL 待办置为已完成，不再永久挂账或强制打开列投影。
- **CDC 巡检等应用就绪后再接管**：避开启用窗口，不再因哈希尚未回填重复登记跳过 DDL 待办。
- **CDC 错误行补中文**：目标重建记录与写入连续失败兜底句补齐中文，中文界面不再夹英文。
- **ETL 范围覆盖推进检查点**：按实际写入范围维护检查点与应用进度，避免重复搬运或续跑错位。
- **ETL 续跑键校验**：NULL 或超长时在行级立即失败并清除已存检查点；原生 upsert 资格判定收紧，避免改到键不同的行。
- **ETL 结果错误键中文化**：列表徽章与「上次运行」卡片按页面语言显示 `error.etl.*`，驱动报错原样保留。
- **元数据图表方言兼容**：聚合改用日历字段分组，MySQL / MariaDB 元数据库的看板与项目曲线不再 500。
- **历史审计行兼容**：恢复 `SYSTEM_DB_TEST` 的读取，v1.14.0 ~ v2.1.0 升级实例打开审计页不再 500。
- **TLS 路径证书健壮性**：惰性校验，TLS 未启用时不阻塞启动；暂存上传 1 小时后回收，超限与暂存接口返回可读 JSON 错误。
- **更新提示健壮性**：「忽略此版本」写库失败不再 500，版本提示与升级进度弹窗不再叠加，开发构建显示「跳过版本比较」而非「更新检查失败」。

## 已知边界

- 自动关闭只覆盖能解析出表名的表 / 索引待办；视图、存储过程、函数、触发器仍需人工对齐。
- 路径证书要求运行账户可读、单个文件不超过 5 MB；删除只清理 Jync 边车与派生文件，不碰外部证书。
- 元数据库支持矩阵为 H2（默认）、MySQL 8、PostgreSQL 16、Oracle 23；MariaDB 11.4 契约测试通过，SQL Server 2022 仅验证 JPA 可移植性。
- 关闭更新检查后导航圆点、看板提示与一键升级均不可用，重新开启即恢复；忽略版本为实例级设置，多实例需分别操作。

升级只需替换 `jync.jar` 并重启；首次启动会自动为旧变更日志补算语句哈希（失败只告警，不阻塞启动），连接、同步项目、ETL 任务、专属迁移与 TLS 证书配置均无需迁移。运行环境仍需 Java 17 或更高版本。
