# Jync v1.14.0

## 新增

- **应用内 HTTPS（TLS 证书上传）**：「系统管理 → 系统配置」新增「TLS 证书」卡，不必再改 nginx 或环境变量。
  - 两种上传方式：**密钥库**（PKCS#12 / JKS + 口令）或 **PEM**（证书链与私钥可分开或合并成一个文件；裸 DER `.cer`、PKCS#7 也能识别）。
  - 证书与加密后的密钥库口令存放在数据目录 `./data/tls`（`tls.properties` 边车是提交点），**不进元数据库、不进配置包**；换实例后重新上传即可。
  - HTTPS 连接器在启动时创建，保存/删除后**需要重启生效**。页面把「已保存 / 已生效 / 等待重启 / 移除待重启」四个事实分开显示，证书到期前 30 天给出提示。
  - 额外连接器手工对齐主连接器的参数上限、表单体积与 URI 编码，启用 `secure` 与 TLSv1.2/1.3；证书损坏或端口冲突导致启动失败时，可用 `JYN_TLS_ENABLED=false` 先救回实例。
  - 可选 HTTP→HTTPS 307 重定向，只信任严格校验过的 Host 或 `app.tls.redirect-host`，不采信 `X-Forwarded-Host`；非法 Host 返回 400。
  - 私钥与叶子证书用签名探测校验，防止「证书传对了、私钥来自别处」只能在重启时才发现；加密私钥与 SEC1 格式会被明确拒绝并提示转换方式。
- **强制 HTTPS 页面可配**：管理员可在系统配置页开关，无需改配置文件重启。
  - 取值优先级为「配置文件 > 数据库 > 默认」，5 秒 TTL 快照，本节点写入立即失效，其他节点在一个 TTL 内收敛。
  - 回环地址与未鉴权的 `GET /login` 始终可达，避免误配后把管理员锁在 403 之外。
  - 配置文件显式设置 `app.security.require-https` 时页面只读，并显示取值来源。
- **配置包导出/导入**：把一个实例的连接、项目、任务等配置整体搬到另一个元数据库。
  - 单文件 `.jync`：JYNC 信封 + AES-256-GCM（AAD 绑定头部）+ PBKDF2-HMAC-SHA256 21 万次，口令加密；单包 ≤ 20 MB，解压后 ≤ 40 MB。
  - 逻辑导出 13 张配置表，可选「包含同步进度与游标」（`sync-progress`、`cdc-positions`、`metadata-snapshots`、`etl-checkpoints`、`alert-states`）；默认不带进度。
  - 包内 `meta` 携带导出端的 `sync.crypto-*` 密钥：导入时先用源密钥解密全部 `enc:` 值，再以目标部署密钥重新加密；解不开即中止，不写半套凭据。
  - 只接受空配置库；所有 id 丢弃并重映射；单例覆盖、用户按 username 合并（目标口令优先）、导入后必须仍有 ADMIN；明文请求导入会把强制 HTTPS 置为关并给出警告。
  - 导入事务提交后再重唤醒连接池、连接健康缓存与同步/ETL/迁移三类调度，每一步独立失败隔离。
- **元数据库连接测试器**：在页面上填入候选 JDBC 地址与驱动类，真的连一次并给出产品/版本与一段 POSIX 安全引用的 `SPRING_DATASOURCE_*` 环境变量块。
  - 四种 JDBC 方案白名单，驱动必须与方案匹配，拒绝换行；用厂商级连接超时，不改 JVM 全局 `loginTimeout`。
  - 只测试、不持久化；哪个库生效始终只由 `SPRING_DATASOURCE_*` 决定。
- **列清洗新增 6 种规则**：手机号、身份证、银行卡、姓名、邮箱的格式保留掩码，以及带可选盐的 SHA-256 哈希，规则总数达到 13 种。
  - 掩码按 code point 保留首字符，不会切断 emoji 代理对后向目标库写入孤立高代理。
  - 哈希列在内容校验时自动跳过，不会误报不一致；只改写写入目标的值，源库不变。
- **系统管理导航组**：「系统配置」（仅管理员）与「系统信息」拆分为独立入口，新增 `SYSTEM_SETTING_SAVE` / `CONFIG_EXPORT` / `CONFIG_IMPORT` / `SYSTEM_DB_TEST` 审计事件，URL 一律脱敏，口令与密文不进日志、审计或页面消息。
- **安全数据边界文档**：新增 [security-data-boundary.md](../security-data-boundary.md)，列出本地落点、出网点与关闭方式、完全离线部署清单、加密存储现状、字段级加密/脱敏与国密算法的能力边界。
- **元数据库迁移集成测试**：同一套用例在 `mysql:8.0` 与 `postgres:16` 上各跑一遍，覆盖导出（含状态）→ 清空 → 目标密钥轮换 → 导入，断言计数、外键重映射、`@Lob` 往返、单例与系统设置生效、历史不随包迁移，以及每个密文都能用目标密钥解出原文。

## 优化与修复

- **CDC 基线不再强制创建二级索引**：结构与数据仍强制开启（CDC 基线是唯一一次全量，关掉会丢行），但索引开关在 CDC 模式下保持可见、按保存值执行。手工建表、自带索引或刻意不在装载期维护索引的场景不再被覆盖。
- **配置包导入恢复 `baselineDone`**：此前恢复的位点被当作「基线未完成」，会整表重跑全量并拉长 CDC 停摆时间；现在按导出值恢复。
- **重新编号的 PG / 崖山 CDC 项目导入时重建基线**：PostgreSQL 复制槽与 YStream 服务名内嵌 project id，导入后 id 变化时旧资源在源端不存在。现在按包内保存的采集策略判断，这两类策略在重新编号后丢弃恢复的基线标记，首次启动自动重新全量，而不是带着旧位点续接后被 park 成 ERROR。binlog / Oracle / SQL Server 的位点与 id 无关，不受影响。
- **PEM 解析改为单次前向扫描**：畸形文件（大量 `BEGIN` 无 `END`）此前逐起点重扫，432 KB 实测 21.7 秒、5 MB 上限约 50 分钟，会钉死上传请求线程；现在遇第一个截断块即停止，复杂度 O(n)，拒绝行为不变。
- **脱敏按 code point 处理首字符**：避免 emoji 代理对被切断后写入孤立高代理。
- **TLS 页面细节修正**：待重启时不再把重定向显示为「关」；强制 HTTPS 被 blocked 且 TLS 已禁用时，提示指向配置文件而不是证书；证书续期重传表单用已保存的端口与重定向选择预填，避免只换证书却悄悄改回默认值。
- **强制 HTTPS 拒绝文案分类**：区分未配置证书、TLS 已禁用、证书过期与等待重启，不再一律提示「重启」。
- **应用内 HTTPS 运行中时回环明文请求也重定向**，不再走 403 或回环豁免。
- 文档同步：部署容器环境变量与卷、配置包的迁移边界、配置文档中两种 HTTPS 部署方式与故障恢复表。

## 已知边界

- 配置包**不迁移**变更日志、审计、性能采样、ETL/迁移运行历史、`sync_task` 租约行、`chunk_checkpoint` 与 TLS 证书。无主键表如果在全量装载进行中迁移，可能产生重复行，建议装载结束后再迁移。
- 配置包中的 PG 复制槽 / YStream 服务名包含旧 project id，导入后新实例会建新资源；确认旧实例不再使用后请手工清理源库残留。
- 应用内 TLS **保存后需重启生效**，不支持运行时不重启热切换，也不内置 ACME 自动签发/续期；免费 DV 证书（90 天）续期后需重新上传并重启。
- `data/tls` 是实例本地目录；多实例部署需要共享 `JYN_TLS_DIRECTORY` 或分别上传。TLS 证书不随配置包迁移。
- 证书可以是 DV / OV / EV 任意一种，但必须由公开信任的 CA 签发并携带中间证书链；私钥须为未加密 PKCS#8 / PKCS#1，或使用 PKCS#12 密钥库。

---

数据库连接、同步项目、ETL 与专属迁移的存量配置不需要改动；升级只需替换 `jync.jar` 并重启。使用应用内 HTTPS 时 `./data` 下会新增 `data/tls` 目录，升级前请照常备份 `./data` 与 `application.yml`。
