# Jync v1.7.6

新增只读数据预览、项目克隆与列清洗规则；把「什么都不做」的配置显式拦下；修复 Oracle 11g / GBK 库与若干界面问题。

## 新功能

- **只读数据预览**：项目详情页可直接查看源库或目标库中某张表的内容，确认数据是否真正落库，无需另开 JDBC 工具。固定 `SELECT *`、表名取自项目自身元数据，单表最多 100 行、单元格超过 500 字符截断、单次请求 30 秒超时；不提供写入、筛选、排序或导出。
- **项目克隆**：详情页新增「克隆项目」，复用新建表单并预填名称、描述与源库；目标库必须重新选择。同步设置原样复制（保留本版本不认识的字段），运行状态（游标、分块检查点、CDC 位点）一概不带入；「首次加载前截断目标表」强制关闭，避免一次克隆变成一键清空目标库。
- **列清洗规则**：写入目标库前按表按列修正字符串，支持去首尾空白、转大写/小写、空白转 NULL、去前缀/后缀、正则替换七种固定操作，按保存顺序依次执行；轮询与日志 CDC 两条写入路径都生效。刻意不是表达式语言，规则可跨所有源/目标方言移植。
- **对象全不选即不同步**：显式取消全部表/视图/存储过程表示「这一类都不同步」，不再被误读成「未配置 = 全选」；此类项目的列表页与详情页禁用「开始同步」「手动跑一轮」。
- **空跑配置不再可启动**：显式无对象，或增量轮询/全量比对下同步选项全部关闭（索引单独开启不构成工作）时，禁用启动并在页面说明原因，服务端同样拒绝（`error.project.no.options`）；日志 CDC 按所选表回放变更，不受该判定影响。
- **CDC 下隐藏轮询开关**：日志 CDC 模式下隐藏表结构、表数据、索引、视图、存储过程五个不参与增量流的开关并显示说明，切回轮询/全量比对后恢复；隐藏不禁用，保存时已存值原样提交。

## 修复

- **Oracle 11g**：`V$LOGMNR_CONTENTS` 没有 `SRC_CON_ID` 列，游标改为按服务端主版本选择，11g 用常量 0 保持结果形状，不再报 ORA-00904。
- **ZHS16GBK 等字符集**：内置与 ojdbc8 同版本的 orai18n，缺它时字符集转换失败、对象列表直接为空的问题不再出现。
- **LogMiner 权限探测**：增加 `SELECT ANY TRANSACTION` 检查——11.2.0.2 上仅持目录角色时，`START_LOGMNR` 后读内容视图仍报 ORA-01031；缺失时给出可直接执行的授权语句。
- **捕获策略表单**：以已保存策略为脏检查基线，探测推荐的勾选不再被当成用户已保存的选择。
- **列清洗边界**：清洗不再改写分块加载的 keyset 边界；保存规则时校验正则与替换串（尾随反斜杠、越界组号等），非法规则当场拒绝，不再等到同步时每轮失败。
- **克隆一致性**：新建行与同步设置在同一事务内提交，失败不会留下空项目。
- **预览安全与提示**：表数据预览与结构查询仅限管理员；预览请求网络失败时给出明确错误提示。

## 测试

- 单元测试 **1503** 个全部通过（默认套件，`*IT` 需 Docker 另跑）。

## 已知边界

- 数据预览是「看一眼」而非数据库客户端：固定 100 行上限、无筛选与排序，超大单元格会被截断。
- openGauss 目标的 upsert 无挂条件位置，源库未动时仍会多报更新。
- 空闲轮仍重读游标边界那一秒的行（迟到事务安全余量），由目标侧守卫吸收。

## 升级

替换 jar 重启即可，表结构随 `ddl-auto: update` 自动演进；升级前备份 `./data`。停机期间的源库变更会在重启后自动补齐。容器部署同步升级镜像 tag 至 `jync:1.7.6`（Docker Compose 与 `deploy/k8s/` 清单已更新）。
