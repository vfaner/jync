# Jync v1.9.0 · Webhook 告警与 ETL 批次

新增 Webhook 告警通知与 ETL 批次，ETL 连接类型扩到 7 种新库；同步链路修复了租约与连接池的一组问题。

## 新增

- **Webhook 告警通知**：同步失败、CDC 异常等按分类推送，支持冷却时间与通用/钉钉/企业微信/飞书格式；地址加密存储，页面只回显尾号。
- **ETL 批次**：同源同目标的多张表共享一对连接与一条调度，组内按顺序执行；成员任务的连接与调度由批次统一管理。
- **ETL 数据库类型**：新增 SAP HANA、Doris、ClickHouse、Hive、Impala、Elasticsearch、MongoDB（Atlas SQL）7 种，另支持 MongoDB 原生驱动源。
- **ETL 多语句脚本**：取数 SQL 支持多语句脚本。
- **看板**：新增内存趋势图与 ETL 运行卡片，支持双布局与滚动切换。
- **游标列索引提示**：轮询任务的游标列缺少索引时，项目详情页直接标出。

## 优化

- 告警设置页在桌面宽屏下两卡并排。
- 连接下拉按源/目标角色分组。
- 独立任务表单提示：同源同目标的多张表建议使用批次。

## 修复

- 网关头模式未强制校验共享密钥。
- 租约丢失被计入失败次数、ERROR 状态被半途解除、元数据库抖动导致停止续租。
- 连接被池回收后不重借，一张慢表拖垮整轮同步。
- 行拷贝缺少独立超时与计数保护，失败提示不准。
- ETL 表单的页面结构、错误归属与调度触发。
- 10 项安全漏洞与代码质量问题。

## 提醒

- 轮询模式靠游标列做增量，请确认源表游标列（如 `updated_at`、自增主键）已有索引；没有索引时每轮都会全表扫描。
- 本次无破坏性变更，替换 `jync.jar` 重启即可；升级前备份 `./data` 与 `application.yml`。
