# Jync v2.2.1

## 新增

- **告警通知语言**：告警设置可选跟随系统、中文或 English，通知正文按配置渲染；配置包携带该字段，旧包缺省按中文处理。
- **告警投递状态与设置审计**：告警设置页显示最近一次投递的时间、成功与否及平台给出的原因；保存告警设置与外部认证设置写入审计。
- **变更日志中文句式**：内容核对、Redis 基线写入、自动建表失败、首次加载前清空失败、结构校验说明、强制释放同步锁六类固定句式在中文界面译出，英文原文仍按原样存库。

## 优化

- **CDC 写入与元数据库压力**：已提交位点至多每秒落库一次，每轮结束强制写出；每张表的 upsert / delete 语句、绑定类型与列清洗规则按运行缓存；空闲轮询按 1s → 2s → 4s → 5s 阶梯退避，来数即回 1s。
- **ETL 写入**：MySQL / PostgreSQL / Oracle / SQL Server 目标在表已存在、键列有精确匹配的唯一索引（或由 Jync 创建、自带主键）时使用原生单语句 upsert，其余目标保持等价实现；模拟 upsert 改为批量化，每事务一次往返。
- **ETL 多实例互斥**：新增 `etl_run_lock` 数据库租约（条件抢占、60 秒过期、看门狗续约），同一任务不会被两个实例同时执行；元数据库不可用时拒绝启动，而不是冒险双跑。
- **安全加固**：告警 Webhook 默认拒绝回环、私网与云元数据地址，内网聊天服务可用 `alert.webhook.allow-private=true` 放开；测试发送与保存复用同一套校验；外部认证改用不跟随重定向的共享 HTTP 客户端，登录后旋转 CSRF token；HTTP→HTTPS 跳转只使用连接的本机地址或 `app.tls.redirect-host`，不再采信 Host 头。

## 修复

- **CDC 整项目停摆**：SQL Server 捕获表无主键或元数据读取失败不再以空指针掐住整条流；PG 逻辑解码被 `max_changes` 截断的半事务不再原地空转；异常链自引用不再让消费线程死循环。
- **CDC 消费者锁泄漏**：PG 消费者的前置步骤失败会绕过唯一的 `lock.close()`，本机信号量归零、数据库租约被看门狗持续续约，项目直到重启进程才解卡；死线程清理现在一并释放租约。
- **CDC 凭据与解码**：Oracle `ORA-01017 / ORA-28000 / ORA-28001` 不再被归为瞬时错误无限重连，直接停车等人工处理；`test_decoding` 的数组列与含撇号的双引号标识符不再把整表或整个项目判成畸形。
- **无主键表全量加载**：目标表非空或无法证明为空时拒绝本轮加载并给出处理办法，不再静默把整表再插一遍。
- **ETL 续跑与租约**：Oracle 的 NLS 日期文本存进检查点后无法读回、中断后永远无法续跑；MongoDB 日期续跑键被改写后每次续跑都报无效；被强杀节点留下的过期租约不再让任务无法删除或批次无法移出；重复键冲突按目标端后写胜出。
- **升级后保存设置 500**：审计动作枚举列在启动时无损改为 `VARCHAR(32)`（H2 / MySQL / MariaDB / PostgreSQL），升级实例保存告警或外部认证设置不再报错。
- **专属迁移**：Elasticsearch 源补取 `_routing`，自定义路由文档不再落到默认分片或误报不一致；`_bulk` 部分失败按成功条数计数；已结束的运行记录不再被崩溃处理改写为失败。
- **Redis 命名空间**：前缀互为包含关系也拒绝保存，避免一次清扫删掉其他项目的键；前缀含 SCAN 通配符时保存、预检与清扫全部拒绝。
- **数据漂移误报**：定长 CHAR 的尾部补空格不再算作内容差异。
- **修复若干小项**（SQL 转换、TLS 证书边车、CDC DDL 校验等）。

## 已知边界

- 告警 Webhook 的私网拦截默认开启，云元数据地址在任何配置下都不允许；内网聊天服务需显式放开。
- 按域名访问或位于 NAT 之后的应用内 TLS 部署必须设置 `JYN_TLS_REDIRECT_HOST`，否则跳转会指向 IP 并与证书域名不匹配。
- `test_decoding` 的数组列无法绑定到目标：含数组列的 INSERT / UPDATE 整行跳过并限流告警，DELETE 仍按主键执行；需要该列数据请改用轮询或全表比对。
- ETL 执行租约依赖元数据库；节点被强杀后最多约一分钟由其他实例接管。专属迁移的定时与手动运行仍只有进程内锁，多实例部署需保证同一任务只在一个节点调度。
- 无主键表的目标探测失败按非空处理；时间戳游标下更新过的行会在下一轮增量里再次插入。

升级只需替换 `jync.jar` 并重启；审计动作列会在启动时自动无损改为文本（失败只告警、不阻断启动），配置包缺少 `language` 字段时按中文归一，连接、同步项目、ETL 任务、专属迁移与 TLS 证书配置均无需迁移。运行环境仍需 Java 17 或更高版本。
