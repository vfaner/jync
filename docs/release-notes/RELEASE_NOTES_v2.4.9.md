# Jync v2.4.9 · 表维护与预览校验、全量进度、CDC 延迟告警与安全加固

## 本版概要

v2.4.9 是 2.4.8 之后的功能与稳定性版本：新增单表后台重载、项目级预览内容校验、
外部基线结构验证、全量进度估算与完成时间、CDC 逐表进度与批量延迟、CDC 延迟告警
和无主键预检；并修复全量累计行数、上次同步、100% 状态、CDC 重放、登录重定向、
ETL 同库识别以及 Mongo / ES / SSO 边界。建议所有 2.4.x 用户升级。

## 新增

- **表维护与预览校验**：支持单表后台重载，可轮询进度、查看结果并取消；预览弹窗
  合并内容校验，按主键顺序展示源/目标前 N 行（10 / 50 / 100 可选），比较行内容与
  两侧列数；支持项目级批量校验、逐表状态、可停止的串行进度和单元格点击复制。
- **外部基线结构验证**：采用外部基线后后台校验目标表结构，记录
  `PENDING / RUNNING / OK / MISMATCH / ERROR` 与问题清单；记录并展示外部基线表范围，
  支持有审计证据的旧基线范围回填，配置包导入导出保留范围信息。
- **全量进度**：全量开始时用统计信息估算行数（不执行 `COUNT(*)`），加载中显示近似
  百分比；记录全量完成时间，加载中显示检查点时间和已复制行数；完成的 Jync 全量显示
  100%，全部完成时隐藏该列。
- **CDC 可观测性**：按变更窗口批量写入逐表已应用行数与上次同步时间；CDC 状态卡和
  `cdc_status` 展示目标批量延迟、事件延迟、位点年龄以及跨节点持久化位点年龄。
- **CDC 参数调整**：`sync.batch-size` 改为每个 JDBC 批次实时读取，本节点调整后下一批
  生效，其他节点约 30 秒收敛；AI 助手可根据 `diagnose_project` 的性能诊断建议批量大小，
  经确认卡执行。
- **CDC 延迟告警与无主键预检**：事件延迟或位点停滞连续三次评估后触发告警，空闲源
  不会误报，恢复后发送恢复通知；预检提示无主键表，CDC 基线遇到无主键表时跳过该表并
  继续其余表基线，不再让整个基线失败。
- **AI 助手**：同步更新提示词、中英文知识库和工具说明，覆盖全量行数/进度、外部基线、
  逐表状态、CDC 性能诊断和参数调整。

## 优化

- 预览校验复用一次源/目标上下文；CDC 逐表进度改为每个变更窗口一次事务写入。
- 轮询单表重载会排空排队的重跑请求，经典全量回退时清理旧分块检查点，空全量保留
  续跑前缀。
- 外部基线验证支持手动重检，并回收异常中断后残留的 `RUNNING` 状态。
- 外部基线范围回填只在确有 adoption 审计证据且项目停止时提供，避免普通基线被误标。
- 单表操作合并到一列，保留轮询专属门禁与访客可见性。
- 项目名提示改为名称下方的白底灰字气泡，带尖角；空间不足时自动翻到上方。
- 全量进度单元格只显示百分比，表名和行数保留在汇总卡，减少重复信息。
- fan-out 移除目标时同步清理该目标的位点、进度和 spool；重建基线时清理全部目标位点。
- 配置包删除从未被读取的 `manifest.json`，`includeState` 以加密信封头为准并校验
  `meta.json` 一致性；旧配置包仍可导入。
- 全量诊断字段（估算行数、完成时间）随配置包导入导出往返，估算写入失败只降级提示，
  不再中断全量。

## 修复

- 全量同步累计行数一直为 0、上次同步不更新、已完成仍显示非 100%，以及游标被清空后
  仍显示 `COMPLETED` 的问题。
- 无主键续跑、经典全量回退、跳过删除周期、空全量收尾等路径下进度和检查点不一致。
- CDC 重放已存在且未变化的行时，共享 upsert 逻辑可能误报唯一键冲突；恢复 CDC 的
  存在性检查语义，轮询继续使用守卫规则。
- fan-out 消费者退出未释放租约、新表 DDL 后重连位点、健康流后重连退避未重置，以及
  启动/停止注册竞态。
- 登录页通过 HTTP 提供时，CSP `form-action 'self'` 阻止 POST 跟随 HTTPS 重定向；
  增加应用自身重定向源和 `app.security.form-action-origins` 配置。
- ETL 保存时的字符串端点比较可被 `localhost` / `127.0.0.1`、DNS 别名或 NAT 地址绕过，
  `OVERWRITE` 可能删除正在读取的源数据；运行前读取数据库物理身份并在探测不可用时
  回退地址比较。
- ETL 重命名仅在 SQL/变量引用 `${taskName}` 时清理续跑检查点。
- Mongo 自定义 URI 查询串中的密码类参数（含 URL 编码键）会绕过加密存储；现在直接拒绝。
- ES → Easysearch 优先用 `cluster_uuid` 判断同一集群，避免别名/IP 写法导致误删源索引。
- Header SSO 不再拦截公共 Prometheus bearer-token 端点。
- 外部基线验证徽章使用静态消息键，修复无法解析的动态表达式；补充模板消息表达式扫描。
- 配置包导入时，认证信封与 `meta.json` 的 `includeState` 不一致会按坏格式拒绝。

## 升级

- jar：备份 `data/` 后替换 `jync.jar` 并重启；或使用「系统信息 → 一键升级」。
- 容器：拉取 `vfaner/jync:2.4.9`（或 `latest`）后重建容器，数据卷保持不动。
- 从 2.4.8 升级无需手工迁移元数据；配置包中的旧 `manifest.json` 会被忽略，不影响导入。
