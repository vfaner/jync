# Jync v2.4.8 · AI 助手增强、会话超时与元数据库容错

## 本版概要

v2.4.8 是 2.4.7 之后的稳定性与运维体验版本：补齐 AI 助手的日志/实例检索与空回复兜底，
新增登录会话超时管理，并让 H2 元数据库异常时不再把整个页面打成无提示的 500。建议所有
2.4.x 用户升级。

## 新增

- **AI 助手工具增强**：新增 `search_logs` 查询当前实例日志、`search_instance_code` 检索
  部署 jar 中的配置/错误消息/常量；模型优先用工具取证，证据不足时仍给出可执行的判断和验证步骤。
- **登录会话超时管理**：默认空闲超时调整为 8 小时（`JYN_SESSION_TIMEOUT` 可覆盖）；
  新增 AI 工具 `update_session_timeout`，管理员确认卡修改，最低 30 分钟、最高 30 天。
- **元数据库故障容错**：H2 关闭或 MVStore 写失败时，页面返回可操作的 503 维护页，API 返回
  JSON 503；更新检查、强制 HTTPS、AI 开关等可选设置读取失败时降级到缓存/默认值。
- **外部元数据库部署**：README、AI 知识库和 Compose 增加 MySQL / PostgreSQL / Oracle
  元数据库配置示例；`docker-compose.release.yml` 提供注释开关；补充 `SYNC_CRYPTO_SALT`
  必须是偶数位十六进制的说明。

## 优化

- 更新检查的导航栏实时结果回写设置页缓存；设置页发现结果不一致时自动刷新一次。
- 支持 Spring Boot 3.2+ nested jar URL，同版本重发制品的 SHA/大小比对恢复可用。
- AI 工具预算耗尽时保留确认卡、草稿与错误状态；Anthropic 工具结果后的收束文本合并到同一条 user 消息。
- 无主键全量重试前确认目标为空，提交后的清理异常不再触发重复 INSERT。
- 新增 UPDT_TM / UPDATE_TM / CREATE_TM 等游标列提示，复合主键表更容易自动识别更新时间列。
- 达梦 LogMiner 归档过滤 `DELETED`/`STATUS`，启动失败仍执行 `END_LOGMNR` 并保留原始归档缺口错误。
- 登录会话超时、部署脚本和 AI 知识库说明统一。

## 修复

- AI 助手实例代码搜索在 Spring Boot nested jar 下扫描不到 `BOOT-INF/classes`；修复长行截取、
  特殊字符偏移、二进制资源误扫和截断标记。
- AI 助手空回复、Anthropic 连续 user 消息、错误/确认卡被工具结果预算截掉等边界。
- Docker Compose 外部元数据库示例的注释与缩进问题，以及非十六进制 `SYNC_CRYPTO_SALT`
  导致的启动失败说明。
- 更新检查设置页与导航栏显示不同版本、同版本重发不提示的问题。

## 升级

- jar：备份 `data/` 后替换 `jync.jar` 并重启；或使用「系统信息 → 一键升级」。
- 容器：拉取 `vfaner/jync:2.4.8`（或 `latest`）后重建容器，数据卷保持不动。
- 从 2.4.7 升级无需手工迁移元数据；外部元数据库部署请先按 README 配置连接，
  已有 H2 数据需导出配置包再导入。
