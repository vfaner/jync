Metadata store unavailable

Jync cannot read or write its metadata store. Check the disk space, permissions and jync.mv.db in /app/data. Back up the data directory before repairing it.

For production, use MySQL / PostgreSQL / Oracle as the metadata store instead.

Restore the data directory and restart Jync.

If those steps cannot fix it, move or delete data/jync.mv.db and restart as a last-resort recovery. This creates an empty database; connections, projects, users and settings are lost and must be reconfigured or restored from a configuration package.
